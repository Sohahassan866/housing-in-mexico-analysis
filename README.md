# housing-in-mexico-analysis
This project explores housing data in Mexico using Python and Jupyter Notebook. It includes data cleaning, visualization, and insights into regional housing patterns. This analysis was completed as part of the WorldQuant University data science curriculum.
## Contents
- Data exploration
- Feature engineering
- Visualizations
- Summary of findings

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook
